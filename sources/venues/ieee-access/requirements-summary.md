# Venue Requirements — IEEE Access

**Submission Format**: PDF + LaTeX or Word source file (both required, must match exactly)
**Template**: IEEE Access (double column, single-spaced)
**Page Limit**: No hard limit; strongly recommended < 20 pages for ease of readability
**Column Layout**: Double column
**Font**: 10pt (per IEEE Access template)
**Abstract Word Limit**: ~200–250 words (no defined abbreviations)
**Blind Review**: No (not blind review — author names and affiliations required)
**Citation Style**: Numbered, order of appearance [1]
**Keywords**: Minimum 3, maximum 10 (called INDEX TERMS)
**Supplementary Allowed**: Yes (max 100 MB for video)
**ORCID**: Required for submitting author (publicly visible profile)
**Author Biographies**: Required for ALL authors — included at the end of the paper body, below references
**AI Disclosure**: Required in Acknowledgements section; any AI-generated section must cite the AI system used

## Special Requirements

1. Double column, single-spaced format using IEEE Access template
2. Both Word/LaTeX source AND PDF must be submitted; content must match exactly
3. File sizes ≤ 40 MB
4. All abbreviations/acronyms must be defined at first use in the body (even if defined in abstract)
5. Keywords must be as accurate as possible (3–10)
6. Short biographies + author photos for ALL authors at end of paper
7. Articles with poor grammar are immediately rejected
8. Do NOT include references that are not relevant to the work
9. Retracted references will cause rejection

## Manuscript Types

The following types are accepted for peer review (select carefully as it is published on the article):
Research Article, Topical Review, Theory, Survey, Perspective, Applied Research,
Negative Result, Methods, Tutorial, Standards, Comment, Reply, Debate, Exposition,
Meta-Analysis, Unsolved Problem.

**Recommended type for this paper**: Research Article
