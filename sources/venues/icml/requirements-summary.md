# Venue Requirements — ICML (International Conference on Machine Learning)

**Submission Format**: PDF (ICML LaTeX style)
**Template**: ICML official LaTeX style file
**Page Limit**: 8 pages (main text) + unlimited references + appendix
**Column Layout**: Double column
**Font**: ICML template defaults (10pt)
**Abstract Word Limit**: ~200 words
**Blind Review**: Yes — double-blind
**Citation Style**: Author-year (natbib)
**Keywords**: Not formally required; select subject areas during submission
**Supplementary Allowed**: Yes (unlimited appendix; reviewers not obligated to read)

## Special Requirements

1. Double-blind: anonymize all identifying information
2. 8-page limit is STRICT for main content; references and appendix don't count
3. Appendix: unlimited but reviewers may not read it
4. Reproducibility checklist is mandatory
5. Code submission encouraged (anonymous GitHub or OpenReview attachment)
6. Ethics review: flag if work involves human subjects, dual use, or societal impact
7. Formatting violations → automatic desk rejection

## Sections (typical structure)

1. Abstract
2. Introduction
3. Related Work
4. Preliminaries / Problem Setup
5. Method
6. Experiments
7. Conclusion
8. References
9. Appendix

## Acceptance Rate

~25–28%
