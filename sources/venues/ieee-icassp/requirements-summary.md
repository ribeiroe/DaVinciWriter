# Venue Requirements — IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP)

**Submission Format**: PDF (IEEE conference format)
**Template**: IEEE conference template (two-column)
**Page Limit**: 4 pages + 1 page references only (5 total)
**Column Layout**: Double column
**Font**: 10pt (IEEE conference template)
**Abstract Word Limit**: ~150 words
**Blind Review**: Yes — double-blind (for initial submission)
**Citation Style**: IEEE numbered, order of appearance [1]
**Keywords**: Index Terms (4–6)
**Supplementary Allowed**: Limited (audio samples via external link)

## Special Requirements

1. STRICT 4+1 page limit — content on page 5 must be references only
2. Double-blind for review; camera-ready includes author names
3. Must use IEEE conference two-column template
4. Figures and tables count toward the 4-page limit
5. Demo papers: 2 pages + 1 page references
6. At least one author must register and present at the conference
7. Overlength papers are automatically rejected
8. Equations must be numbered consecutively

## Sections (typical structure)

1. Abstract (with Index Terms)
2. Introduction
3. Related Work (brief)
4. Proposed Method
5. Experiments
6. Results and Discussion
7. Conclusion
8. References

**Note**: Due to severe space constraints, Background/Related Work is often compressed into the Introduction or a single brief section.

## Acceptance Rate

~45–50%
