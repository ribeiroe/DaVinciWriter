# Venue Requirements — Elsevier Journal of Systems and Software (JSS)

**Submission Format**: PDF + source (LaTeX or Word) via Editorial Manager
**Template**: Elsevier article template (elsarticle)
**Page Limit**: No hard limit; typical papers 15–30 pages (single column review format)
**Column Layout**: Single column (review format); double column in print
**Font**: Elsevier template defaults
**Abstract Word Limit**: ~200–300 words
**Blind Review**: Yes — double-blind
**Citation Style**: Numbered, order of appearance [1] (Elsevier numbered style)
**Keywords**: 3–6 keywords (from Elsevier keyword list when possible)
**Supplementary Allowed**: Yes (data in brief, Mendeley Data)

## Special Requirements

1. Double-blind: anonymize all author information in manuscript
2. Highlights: 3–5 bullet points (max 85 characters each) summarizing key findings
3. Graphical abstract encouraged
4. Data availability statement required
5. CRediT author contributions required
6. Declaration of competing interests mandatory
7. Research data must be deposited if the paper is data-intensive
8. For SLR/mapping studies: PRISMA flow diagram expected
9. Ethical approval statement for human participant studies

## Sections (typical structure)

1. Abstract
2. Introduction
3. Background / Related Work
4. Research Method
5. Results
6. Discussion
7. Threats to Validity
8. Conclusion
9. References

## Impact Factor

~3.5 (Q1 in Software Engineering)
