# Venue Requirements — ACM SIGSOFT International Conference on Software Engineering (ICSE)

**Submission Format**: PDF (ACM format)
**Template**: ACM Primary Article Template (acmart, sigconf)
**Page Limit**: 10 pages + 2 pages for references only
**Column Layout**: Double column
**Font**: 10pt (ACM template default)
**Abstract Word Limit**: ~250 words
**Blind Review**: Yes — double-blind (no author names, affiliations, or self-identifying references)
**Citation Style**: ACM Reference Format (numbered, bracketed)
**Keywords**: CCS concepts required + author-defined keywords
**Supplementary Allowed**: Yes (separate supplementary material, not counted in page limit)

## Special Requirements

1. Double-blind: remove ALL author-identifying information from the manuscript
2. Self-citations must be written in third person ("Prior work [X] showed...")
3. Must use ACM acmart template with `sigconf` option
4. CCS (Computing Classification System) concepts are mandatory
5. Ethical approval must be disclosed for studies involving human participants
6. Artifact evaluation encouraged (badges: Available, Reusable, Replicated)
7. Data availability statement recommended

## Sections (typical structure)

1. Abstract
2. Introduction
3. Background / Motivation
4. Approach / Methodology
5. Evaluation / Results
6. Discussion / Threats to Validity
7. Related Work
8. Conclusion
9. References

## Acceptance Rate

~20–24% (highly competitive, top SE venue)
