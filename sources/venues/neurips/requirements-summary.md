# Venue Requirements — NeurIPS (Conference on Neural Information Processing Systems)

**Submission Format**: PDF (NeurIPS LaTeX style)
**Template**: NeurIPS official LaTeX style file (neurips_2026.sty)
**Page Limit**: 9 pages (main text) + unlimited references + supplementary
**Column Layout**: Single column
**Font**: NeurIPS template defaults (Times-like, 10pt)
**Abstract Word Limit**: ~300 words (one paragraph)
**Blind Review**: Yes — double-blind
**Citation Style**: Author-year or numbered (NeurIPS style)
**Keywords**: Not formally required; use subject areas during submission
**Supplementary Allowed**: Yes (appendix + code; reviewers not obligated to read)

## Special Requirements

1. Double-blind: anonymize all author and institution references
2. 9-page limit is STRICT for main content; references do not count
3. Supplementary materials: unlimited pages but reviewers may ignore them
4. Ethics statement required if applicable (does not count toward page limit)
5. Reproducibility: code submission encouraged; reproducibility checklist mandatory
6. Broader Impact statement expected
7. Must check the NeurIPS Paper Checklist during submission
8. Desk rejection for formatting violations

## Sections (typical structure)

1. Abstract
2. Introduction
3. Related Work
4. Method / Approach
5. Experiments
6. Results
7. Conclusion
8. Broader Impact (if applicable)
9. References
10. Appendix (supplementary)

## Acceptance Rate

~25–26%
