# Venue Requirements — ACM SIGSOFT Foundations of Software Engineering (FSE)

**Submission Format**: PDF (ACM format)
**Template**: ACM Primary Article Template (acmart, sigconf)
**Page Limit**: 12 pages + 2 pages references only
**Column Layout**: Double column
**Font**: 10pt (ACM template default)
**Abstract Word Limit**: ~250 words
**Blind Review**: Yes — double-blind
**Citation Style**: ACM Reference Format (numbered, bracketed)
**Keywords**: CCS concepts required + author-defined keywords
**Supplementary Allowed**: Yes (appendix not counted in page limit)

## Special Requirements

1. Double-blind: remove all identifying information
2. Self-citations in third person
3. Must use ACM acmart template with `sigconf` option
4. CCS concepts are mandatory
5. Artifact evaluation track available (separate submission for badges)
6. Data availability encouraged (Zenodo, Figshare)
7. Ethics statement required for human-subject studies
8. Clear contribution statement in the introduction

## Sections (typical structure)

1. Abstract
2. Introduction
3. Motivating Example (optional)
4. Approach / Methodology
5. Evaluation
6. Results
7. Discussion / Threats to Validity
8. Related Work
9. Conclusion
10. References

## Acceptance Rate

~20–25%
