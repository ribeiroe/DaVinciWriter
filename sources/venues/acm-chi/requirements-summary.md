# Venue Requirements — ACM CHI Conference on Human Factors in Computing Systems

**Submission Format**: PDF (ACM format) + supplementary materials
**Template**: ACM Primary Article Template (acmart, sigchi)
**Page Limit**: No hard limit (papers typically 10–18 pages + references)
**Column Layout**: Single column (new ACM format since 2023)
**Font**: Default ACM template font
**Abstract Word Limit**: ~150 words
**Blind Review**: Yes — double-blind with author response (rebuttal) phase
**Citation Style**: ACM Reference Format (numbered, bracketed)
**Keywords**: CCS concepts required + author-defined keywords
**Supplementary Allowed**: Yes (video figures encouraged, max 5 min)

## Special Requirements

1. Double-blind: anonymize all author information
2. New single-column format required (acmart with `manuscript` option)
3. Papers can be any length but reviewers may penalize unnecessarily long papers
4. Video figures (up to 5 min) strongly encouraged for interactive systems
5. Studies with human participants must report IRB/ethics approval
6. Accessibility: alt text for all figures, accessible PDF
7. Contribution types must be explicitly stated: Empirical, Artifact, Methodological, Theoretical, Dataset, Survey, Opinion

## Sections (typical structure)

1. Abstract
2. Introduction
3. Related Work
4. System Design / Methodology
5. User Study / Evaluation
6. Results
7. Discussion
8. Limitations
9. Conclusion
10. References

## Acceptance Rate

~25–28%
