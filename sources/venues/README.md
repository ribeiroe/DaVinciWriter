# Venue Guidelines and Templates

Place conference and journal author guidelines here, organized in subfolders by venue.

## Folder Structure

```
venues/
  ieee-icassp-2026/
    author-guidelines.pdf
    IEEEtran.cls
    requirements-summary.md   ← auto-generated by /set-venue
  acm-chi-2026/
    sigconf-template.zip
    author-guidelines.pdf
  elsevier-pattern-recognition/
    elsarticle-template.zip
    guide-for-authors.pdf
```

## How to Add a Venue

1. Create a subfolder named after the venue (lowercase, hyphens): `sources/venues/<venue-name>/`
2. Drop the author guidelines PDF and any LaTeX/Word templates into the folder.
3. Run `/set-venue` — it will parse the guidelines and create a `requirements-summary.md`.

## Where to Find Guidelines

- **IEEE conferences**: [https://www.ieee.org/conferences/publishing/templates.html](https://www.ieee.org/conferences/publishing/templates.html)
- **ACM conferences**: [https://www.acm.org/publications/proceedings-template](https://www.acm.org/publications/proceedings-template)
- **Elsevier journals**: [https://www.elsevier.com/authors/tools-and-resources](https://www.elsevier.com/authors/tools-and-resources)
- **Springer LNCS**: [https://www.springer.com/gp/computer-science/lncs/conference-proceedings-guidelines](https://www.springer.com/gp/computer-science/lncs/conference-proceedings-guidelines)
- For other venues, look for an "Author Guidelines" or "Submission Instructions" link on the venue's official website.

## Notes

- The compliance checker reads `requirements-summary.md` and the raw guidelines together.
- If you update the guidelines (e.g., for a new submission cycle), replace the files and re-run `/set-venue`.
