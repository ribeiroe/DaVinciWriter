# Venue Requirements — IEEE Transactions on Software Engineering (TSE)

**Submission Format**: PDF via ScholarOne + source files
**Template**: IEEE Transactions template (journal format)
**Page Limit**: ~25 pages (regular paper), ~12 pages (short paper), single-spaced two-column
**Column Layout**: Double column
**Font**: 10pt (IEEE Transactions template)
**Abstract Word Limit**: ~200 words
**Blind Review**: Yes — double-blind
**Citation Style**: IEEE numbered, order of appearance [1]
**Keywords**: IEEE-style Index Terms (5–10)
**Supplementary Allowed**: Yes (online appendix, replication package)

## Special Requirements

1. Double-blind: author anonymity must be maintained
2. Clearly state the paper's contributions in the introduction
3. Must use IEEE Transactions LaTeX/Word template
4. Online appendix for detailed results, proofs, or replication materials
5. Reproducibility: replication package expected for empirical studies
6. Prior publication policy: substantial extension required over conference versions (≥30% new content)
7. If extending a conference paper, clearly identify new contributions

## Sections (typical structure)

1. Abstract
2. Introduction
3. Background and Motivation
4. Approach / Methodology
5. Evaluation
6. Results
7. Discussion and Threats to Validity
8. Related Work
9. Conclusion
10. References
