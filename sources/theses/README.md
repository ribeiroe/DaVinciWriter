# Theses

Place Master's and PhD dissertations here.

## Accepted Formats

- PDF (preferred)
- Markdown (`.md`)
- Plain text (`.txt`)

## Example Contents

```
theses/
  smith-john-phd-2023-efficient-transformers.pdf
  garcia-maria-msc-2024-speech-enhancement.pdf
```

## Notes

- Run `/ingest-sources` after adding new files to update the knowledge base.
- Each thesis will be summarized and stored in `output/knowledge/sources/`.
