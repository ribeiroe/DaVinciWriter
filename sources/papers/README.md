# Reference Papers

Place related-work and background research papers here.

## Accepted Formats

- PDF (preferred)
- Markdown (`.md`)
- Plain text (`.txt`)

## Example Contents

```
papers/
  vaswani2017-attention-is-all-you-need.pdf
  he2016-deep-residual-learning.pdf
  devlin2019-bert.pdf
```

## Notes

- Run `/ingest-sources` after adding new files.
- Only papers ingested here will be eligible for citation in the generated manuscript.
- Do NOT place your own previously written papers here — use `sources/my-papers/` instead.
