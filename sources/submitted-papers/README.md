# Submitted Papers

Place papers you have already submitted (and received reviews for) in this folder.

Supported formats:
- `.pdf` — will need text extraction (run `pdftotext paper.pdf paper.txt` or use your PDF reader's export)
- `.txt` — plain text export of your paper
- `.md` — Markdown version

## Usage

Run `/import-paper` to split a submitted paper into section files in `output/<paper-slug>/`, making it ready for:
- `/revise-paper` — systematic revision based on reviewer feedback
- `/coach-revision` — guided walkthrough of reviewer comments
- `/draft-rebuttal` — point-by-point response letter
- `/improve-paper` — expand and strengthen before resubmission
