# My Response Letters

Place your previously written response/rebuttal letters in this folder.

These letters are used to learn your **response-letter style** — tone, structure, argumentation, and formatting preferences — so that any new rebuttal or author-response document generated by DaVinci matches the way you actually write to reviewers.

## What to put here

- Response-to-reviewers letters from previous journal or conference submissions
- Point-by-point rebuttal documents
- Major-revision or minor-revision cover letters addressed to the editor/program committee
- Any author-response document you have previously submitted

## Supported formats

`.txt`, `.md`, `.pdf`, `.docx`

## How it is used

When you run `/draft-rebuttal` or `/revise-paper`, the system:

1. Reads all files in this folder to learn your rebuttal style
2. Extracts patterns: opening formula, tone (deferential / assertive / collegial), how you handle push-back, how you frame changes made, how you structure per-reviewer sections, typical response length per comment
3. Saves a profile to `output/knowledge/response-letter-profile.md`
4. Applies the profile when drafting new response letters

## Example

A file like `ieee-access-2024-response-round1.txt` containing your previous point-by-point response is ideal.
