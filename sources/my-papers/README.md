# My Previously Published Papers

Place your own previously written and published papers here. These are used exclusively for writing style learning — not as citation sources.

## Accepted Formats

- PDF (preferred)
- Markdown (`.md`)
- Plain text (`.txt`)

## Example Contents

```
my-papers/
  my-paper-icassp-2024.pdf
  my-paper-interspeech-2023.pdf
  my-paper-tnnls-2022.pdf
```

## Notes

- Run `/learn-style` after adding new papers to update your style profile.
- The more papers you add, the more accurate and representative the style profile becomes.
- Papers added here are **never cited** in generated manuscripts. They are analyzed for prose patterns only.
- Your style profile is saved to `output/knowledge/style-profile.md` and persists between sessions.
