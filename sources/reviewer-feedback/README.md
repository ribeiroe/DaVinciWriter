# Reviewer Feedback

Place real reviewer comments received after submission here — one file per review round.

- Supported formats: `.md`, `.txt`, `.pdf`
- Naming convention: `<paper-slug>-round-<N>.md` (e.g., `my-paper-round-1.md`), or a forwarded PDF from the venue.
- Used by `/revise-paper` and `/draft-rebuttal` for traceability across revision rounds.

Files in this folder are personal research data and are **not** committed to git (see `.gitignore`).
